# 1.20.0 — Meow 行为体检与 CPR 3.44.0

发布日期：2026-11-09

| 项目 | 值 |

| CPR 宿主 | `>=3.44.0, <3.45.0` |
| 插件版本 | 1.20.0 |
| SDK 提交 | `c622f085748f812936a7371fcc85d1621fa72ca8` |
| 运行模式 | `trustedProcess` |

## 新增

- **Meow 体检页面**：在插件页面新增独立标签页，选择账号、计量 Key、请求模型、对照基线与 36/72/108 题档后开始检测。
- **行为指纹检测**：集成 Meow LLM Detector 4.5.4 与 GPT 基线 `4.5.3-predictive.2`，离线计算行为匹配度、匹配模型与判定阈值。
- **逐题串行执行**：每题单独请求，单题 90 秒上限；失败自动暂停，按 50% 重试预算继续，支持暂停、继续、结束与删除。
- **独立状态空间**：Meow 任务写入 `meow` 私有命名空间，保留 16 个槽位；与 ModelTrace 检测任务、定时计划、账户处理互不影响。
- **报告**：展示结论（一致 / 不匹配 / 证据不足）、匹配模型、各候选匹配度与阈值、有效样本进度与逐题请求记录。

## 变更

- 宿主范围升级至 CPR 3.44.0，SDK 固定至 3.44.0 提交。
- 评分运行时同时内置 `vendor/modeltrace` 与 `vendor/meow`；运行时刷新脚本与许可证收集已覆盖 Meow。
